# Muscle guide library

Muscle groups are seeded from machine movement relationships in `scripts/setup-db.ts`. The repository returns the linked muscle records with each machine so a member can open a short explanation and browse related equipment.

The current beginner catalog covers chest, back, shoulders, triceps, biceps, legs, glutes, and calves. English copy is in the seed script and Arabic labels, regions, explanations, and starter tips are in `data/translations.ar.json`.

Keep explanations focused on general movement roles. Avoid medical claims, pain diagnosis, or promises about results. Expand the library only when each translation and related-machine link is ready.
