# YFLB Fitness Academy — style lock

- Brand spelling: **YFLB Fitness Academy**.
- Use the black YFLB logo on light surfaces and the white logo on dark surfaces.
- Visual direction: athletic editorial, high contrast, typographic, grounded in real gym equipment.
- Warm orange marks the main action and selected states. Use chalk/white surfaces and ink in light mode; graphite and off-white in dark mode.
- Use Barlow Condensed for headings and Barlow for interface text, with system fallbacks.
- Keep the first screen focused on one beginner need and an obvious next action.
- Keep machine search, category filters, and saved equipment together.
- Avoid fake member data, dashboard stats, noisy gamification, crowded cards, and decorative gradients.
- Keep guidance readable and beginner-first. Review training instructions with a qualified professional before production.
- Preserve keyboard focus, readable contrast, reduced-motion support, and responsive touch targets.
