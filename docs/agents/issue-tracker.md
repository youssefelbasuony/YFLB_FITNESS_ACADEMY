# Issue tracker

Provider: local Markdown. The repository has no configured Git remote.

- Put each feature or issue in `.scratch/<feature>/`.
- Keep a concise `README.md` or issue note with goal, context, acceptance criteria, and status.
- Link related feature notes rather than copying them.
- Pull requests are not a request surface (`prs_as_request_surface: false`).
- When a remote is added or work moves to an external tracker, update this document first.
