# YFLB Fitness Academy — master documentation

## Product summary

YFLB Fitness Academy is a beginner-first gym companion. It helps a new member discover the equipment available in their gym, understand how to use a machine, learn the muscle groups involved, and start a manageable workout routine.

## Active product direction

The current user request supersedes inherited Night Gym Academy positioning and any old recommendations in the source archive. Keep the YFLB Fitness Academy name, use the supplied light/dark logo variants, focus on first-time and first-year gym members, and prioritize clarity over gamification or professional-coach certification.

## Current build

The current build is a Next.js App Router application with React, TypeScript, Node.js route handlers, Better Auth, and SQLite. Its runtime code is in `app/`, `components/`, `lib/`, and `scripts/`; seed content is in `data/` and the SQLite schema is in `db/`. The former static prototype is kept in `archive/prototype-2026-11-02/` for reference.
