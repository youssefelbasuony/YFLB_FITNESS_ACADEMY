# Environment Variables

Never commit `.env`, `.env.local`, Vercel environment exports, or secret values. `.env.example` contains placeholders only.

| Variable | Local | Vercel Preview/Production | Purpose |
| --- | --- | --- | --- |
| `BETTER_AUTH_SECRET` | Required | Required | Signs Better Auth cookies/tokens; stable secret at least 32 characters. |
| `BETTER_AUTH_URL` | `http://127.0.0.1:3000` | Exact deployment origin | Better Auth base URL and trusted origin. |
| `DATABASE_PROVIDER` | `sqlite` | `postgres` | Explicit provider; app also detects a Postgres URL. |
| `DATABASE_PATH` | `data/yflb.sqlite` | Not used | Optional local SQLite path. |
| `POSTGRES_PRISMA_URL` | Optional | Required for runtime | Supabase pooler URL used by serverless app requests. |
| `POSTGRES_URL_NON_POOLING` | Optional | Migration shell only | Direct/session connection preferred by one-off migrations. |
| `ADMIN_EMAIL` | Optional for local one-time claim | Required | Exact owner account email permitted to access admin. |
| `ADMIN_ACCESS_KEY` | Generated by explicit local setup | Required | Separate private admin gate key, at least 32 characters. |
| `SUPABASE_URL` | Optional | Required for server upload/delete | Project URL for server-side Storage client. |
| `SUPABASE_SERVICE_ROLE_KEY` | Optional | Required for server upload/delete | Private server key; never expose in browser code. |
| `NEXT_PUBLIC_SUPABASE_URL` | Optional | Required for browser upload | Project URL, safe to expose. |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Optional | Required for browser upload | Publishable key, safe to expose; signed tokens authorize uploads. |
| `SUPABASE_STORAGE_BUCKET` | `yflb-training-videos` | `yflb-training-videos` | Public-read exercise media bucket, with owner-only writes. |

Vercel environment values are independently scoped. Set and verify Preview before Production. A successful Vercel-Supabase integration does not prove that the application is reading from Supabase; confirm `DATABASE_PROVIDER`, runtime queries, and Preview data persistence.
