# UI overview

## Navigation

- **Home:** first-time orientation, machine search, filters, muscle groups, and starter plan
- **Academy:** equipment learning library
- **Workout:** sample first week and account-backed completion state
- **About:** product principles

The interface launches in Arabic with an English control and light/dark theme switch in the header. Desktop uses a compact forest-green side rail; phones use bottom navigation. The machine catalog and all sample guide copy follow the selected language. Large search and filter controls support use on a phone at the gym.

## Main interaction loop

Choose a machine available at the gym → open its guide → learn the setup and movement → inspect linked muscles → save it to My Gym. A signed-in member’s selections are stored in SQLite against their user ID.

## Guide states

A guide presents an instructor video when uploaded. Before an upload, it shows a clearly labelled placeholder. Admin video upload appears only when the signed-in email matches the server-side `ADMIN_EMAIL` setting.

## UX constraints

Avoid fake account or progress data. Keep search and filters together, show an explicit empty state when My Gym has no machines, and announce errors through accessible status text.
